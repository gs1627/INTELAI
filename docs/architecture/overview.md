# Intel AI PC Arena prototype architecture

The Vite + React + TypeScript frontend owns presentation, the anonymous timed game session, persona and explainable recommendation rules. It talks to the optional FastAPI API for anonymous sessions, mission receipts, recommendations, and handoff. Browser storage preserves the active timer anchor and journey state across navigation and refresh. The API uses SQLite locally and psycopg 3 PostgreSQL when `DATABASE_URL` is configured; Vercel `/tmp` SQLite is explicitly ephemeral.

Actual local hardware work belongs to `local-runner`, a separate localhost FastAPI companion. The runner reports detected OpenVINO devices, but detection alone does not verify inference. It deliberately returns `NOT VERIFIED` until a compatible model artifact, fixed benchmark contract and captured runtime evidence are configured. The web build remains playable without this process.

The included laptop catalogue and comparison fixtures are illustrative `SAMPLE DATA`. They are not inventory, Intel-certified measurements, or purchasing performance claims. The API exposes benchmark definitions, signed result ingestion, admin approval gates, and comparisons that return only approved verified records. No historical measurements are bundled. Local companion responses currently remain `DEMO / NOT VERIFIED`: device detection alone does not establish model inference. Associate handoffs use random expiring tokens stored as hashes; demo associate login defaults off on Vercel.
